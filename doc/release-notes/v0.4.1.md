v0.4.1 – Key exchange and identity verification

Rooms no longer need a key passed by hand, and peers have identities
that can be checked.

Added:
- ECDH key exchange (X25519 with crypto_box): --create makes a room
  with a fresh key, --join receives the key from a member. The
  graphical client gets Create Room, Join Room and Connect.
- Ed25519 identities with trust on first use: the first key seen for a
  peer is remembered, and a different one triggers a warning.
- A script that builds a minimal static FFmpeg for Windows, about 5 MB
  instead of about 200 MB of DLLs.

Changed:
- All documentation rewritten in English.

Fixed:
- setsockopt on Windows; static linking of ncrypt, crypt32 and iconv.

Downloads: fear-linux-x86_64.zip, fear-windows-x86_64.zip.

Android: https://github.com/shchuchkin-pkims/fear-mobile/releases/tag/v0.4.1
