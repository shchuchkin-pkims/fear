v0.1.0 – First public build

The first public build: a console client and relay server, a graphical
client and a key exchange utility.

Added:
- Console client and relay server (fear): rooms and end-to-end
  encrypted messages (XChaCha20-Poly1305) under a room key shared out
  of band.
- Graphical client (fear_gui) on Qt.
- key-exchange: an interactive X25519 tool for passing a room key over
  an untrusted channel.

Downloads: fear-windows-x86_64.zip, fear-windows-x86_64.exe,
fear_v0.1.0-windows-x86_64.rar.
