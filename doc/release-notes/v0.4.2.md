v0.4.2 – TCP media relay

Calls work where UDP does not: through NAT, VPNs and firewalls, voice
and video now go through the relay over TCP.

Added:
- TCP media relay (message type 17): each call opens its own TCP
  connection to the relay, which forwards the media to the room.
- TCP keep-alive on the relay: a dead connection is noticed in about
  90 seconds (idle 60 s, interval 10 s, 3 probes).
- The relay explains why it rejects a duplicate name before it closes
  the connection.
- The settings dialog checks for a new version when it opens.
- Call settings are remembered between sessions.
