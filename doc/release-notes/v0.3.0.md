v0.3.0 – File transfer and AES-256-GCM

File transfer, AES-256-GCM everywhere, and safer handling of room keys.
The first Android client was released alongside.

Added:
- Encrypted file transfer with a CRC32 integrity check.
- Audio devices are listed with their host API, so the same device no
  longer appears twice.
- Build scripts for Windows and Linux.

Changed:
- AES-256-GCM replaces XChaCha20-Poly1305 for messages and calls, for
  the sake of the Android client.
- A room key is printed once and never saved to disk; the graphical
  client copies it to the clipboard. Keys are read from stdin or
  --key-file; --key, visible in the process list, is deprecated.
- The updater installs zip archives.
- The graphical client was redesigned, and documentation was added.

Downloads: fear-linux-x86_64.zip, fear-windows-x86_64.zip.

Android: https://github.com/shchuchkin-pkims/fear-mobile/releases/tag/v0.3.0
