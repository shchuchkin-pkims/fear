v0.5.1 – Security release

Fixes every Critical and every High finding of the 2026-07 audit except
forward secrecy, which is deliberately left for the Phase C crypto work.

Critical:
- Stack overflow decrypting media stats packets, reachable without a room
  key (audio and video).
- Buffer overflow from a signed length comparison in the TCP media relay,
  triggerable by an untrusted relay server.
- Integer overflow in the server's BLOB_PUT length check - one packet
  crashed the whole relay.
- Stack overflow parsing a file-transfer filename, triggerable by any room
  member.
- ECDH key exchange accepted an unsigned or badly signed room key on all
  three clients, which made a transparent MITM possible.

High:
- Updates are now signed and verified (Ed25519), and Zip Slip archives are
  rejected.
- Web bridge no longer acts as an open TCP proxy; adds CSP and limits.
- Server survives slow-drip and slow-reader denial of service.
- Line-injection through the CLI's stdout could forge a "verified" badge.

Known issue: the release archives hold only fear and fear_gui – calls
and the updater are missing. Fixed in v0.6.0.

Binaries are built and signed by CI. Verify a download against the public
key in updater/updater.conf before installing.

Compatibility: the mandatory ECDH signature breaks interoperability with
0.5.0 and earlier. Update every client together.
