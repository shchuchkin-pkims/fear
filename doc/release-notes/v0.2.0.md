v0.2.0 – Voice calls

Encrypted voice calls between two devices, and an updater.

Added:
- audio_call: voice calls with Opus over UDP, encrypted with the room
  key (XChaCha20-Poly1305), started from the graphical client.
- Updater: checks GitHub for a newer release and installs it.
- Key exchange from the graphical client's menu.
- A CMake build for the whole project.

Downloads: fear-linux-x86_64.zip, fear-windows-x86_64.zip.
